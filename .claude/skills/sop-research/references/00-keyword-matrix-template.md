## SERP 竞争度判断标准

```
低竞争：首页占比 ≤ 5/10，有内页/论坛/小站排名，新站可攻
中竞争：首页占比 6-8/10，全是正规站但非大品牌
高竞争：首页占比 ≥ 9/10，全是高权重站首页（Wikipedia、大品牌等）
```
