The official GPT Image 2 model page lists image input and image output, which makes it suitable for editing workflows as well as generation. The main skill is prompt control. You need to protect the subject, identity, label, layout, or camera angle while changing only the intended part.

This guide covers background replacement, lighting adjustment, object replacement, poster refinement, and text edits.

## The Editing Prompt Formula

Use this structure:

```text
Keep [parts that must not change] unchanged.
Change [specific part] to [new result].
Preserve [identity, label, camera angle, lighting, or composition].
Remove [unwanted issue].
Do not [specific failure to avoid].
```

The first sentence is the most important. If you do not protect the subject, the edit can drift.

## Background Replacement Prompt

```text
Keep the product, label, shape, and camera angle exactly the same. Replace the plain background with a clean light-gray studio sweep. Add realistic contact shadow and subtle reflection. Do not change the label text or product color.
```

Use this for ecommerce cleanup, ad variants, and product page consistency.

## Lighting Improvement Prompt

```text
Keep the subject and composition unchanged. Improve exposure, add soft directional light from the left, reduce harsh shadows, and make the material texture look natural. Do not change the product shape, label, or background layout.
```

Lighting prompts should name the direction and problem. "Make it premium" is less helpful than "soft directional light from the left" or "reduce harsh shadows."

## Object Replacement Prompt

```text
Replace the white ceramic mug with a matte black travel tumbler. Keep the desk, laptop, lighting, shadows, camera angle, and perspective realistic. Match the new object to the scene. Do not change any other objects.
```

Object replacement is most reliable when the replacement has a clear physical role in the scene. Ask the model to match perspective and lighting.

## Poster Refinement Prompt

```text
Keep the same poster concept and main image. Make the headline "CREATE FORWARD" larger and readable. Improve spacing, reduce clutter, increase contrast, and remove any random or misspelled text. Keep the dark cyan and emerald palette.
```

This is useful when a generated poster has good art direction but weak hierarchy. For poster-specific prompt systems, read the [GPT Image 2 poster prompts guide](/blog/gpt-image-2-poster-prompts).

## Text Correction Prompt

```text
Keep the design, layout, colors, and image unchanged. Replace the headline with exact text "PROMPTS THAT WORK". Remove any extra text. Make the headline sharp, centered, and readable on mobile.
```

Text edits should be narrow. If you ask for a text correction and a full redesign in one pass, you create more ways for the image to drift.

## What To Avoid

Avoid vague edit prompts:

- Make this better.
- Improve everything.
- Make it more professional.
- Fix the text and change the style and add more details.

Use concrete instructions instead:

- Replace the background.
- Keep the label unchanged.
- Make the headline larger.
- Remove extra text.
- Match the original camera angle.
