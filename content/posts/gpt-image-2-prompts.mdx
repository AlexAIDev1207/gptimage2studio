OpenAI describes GPT Image 2 as a state-of-the-art image generation model for high-quality generation and editing, with text and image inputs and image output. That matters for prompts because the model can respond to both a written brief and visual references. The strongest results usually come from prompts that read like a compact creative direction document.

This guide gives you reusable GPT Image 2 prompts for product photos, posters, ads, infographics, and UI mockups. Use them as starting points, then replace the brand, text, subject, and output format.

## The Prompt Formula

A reliable GPT Image 2 prompt usually has seven parts:

1. Asset type: product photo, poster, ad, infographic, UI mockup, thumbnail.
2. Subject: what must appear in the image.
3. Exact text: put important words inside quotes.
4. Layout: framing, hierarchy, composition, and spacing.
5. Style: lighting, color, camera, material, or design reference.
6. Format: aspect ratio, orientation, and intended channel.
7. Constraints: what to avoid, what must stay readable, what should not change.

Here is the base pattern:

```text
Create a [asset type] for [audience or use case]. Show [subject] with [key details].
Include exact text: "[headline]" and "[supporting text]".
Use [layout], [lighting/style], and [color direction].
Format: [aspect ratio or channel]. Keep text readable. No extra logos, no watermark.
```

If you need direct editing instead of a new image, use the same structure but start with "Keep the original subject and camera angle." For editing examples, read the [GPT Image 2 image editing prompts guide](/blog/gpt-image-2-image-editing-prompts).

## Product Photo Prompts

Product prompts should describe the selling surface, material, lighting, label text, and shopper context. Use product-specific language instead of generic words like "premium".

```text
Create a clean ecommerce product photo of a matte black insulated travel tumbler on a light stone surface. Soft daylight from the left, realistic contact shadow, subtle reflection, sharp edges, natural metal texture. The label text must read "NORTHLINE". Minimal background, no extra props, 4:5 vertical.
```

```text
Create a Shopify hero image for a skincare serum bottle named "HYDRA GLOW". Show the bottle on white marble with water droplets, soft spa lighting, and a small botanical accent. Keep the label readable. Commercial product photography, crisp glass, no fake brand logos, 16:9.
```

Use product photos when the buyer needs trust. The output should show what the object is, what it feels like, and how it fits into a product page. If ecommerce is your main workflow, use the dedicated [product photo prompt guide](/blog/gpt-image-2-product-photo-prompts).

## Poster And Event Prompts

Poster prompts need hierarchy. Tell GPT Image 2 which text is the headline, which is supporting copy, and where the call to action should sit.

```text
Design a launch event poster for an AI design summit. Headline text: "CREATE FORWARD". Subtitle: "AI Design Summit 2026". Use a strong central geometric composition, cyan and emerald accents on a dark background, clean sans serif typography, clear date block, high contrast, 4:5 vertical.
```

```text
Create a modern menu board poster for a matcha cafe. Headline: "KIZUNA MATCHA". Include three readable menu items: "Iced Matcha", "Yuzu Latte", "Black Sesame Float". Warm counter lighting, Japanese minimal design, cream paper texture, green accent, no misspelled text, 16:9.
```

The difference between a usable poster and a decorative image is text discipline. Keep the prompt short enough that every word matters, and keep the text inside the image limited to the words you actually need.

## Social Ad Prompts

Social ads need a stronger hook and a clear channel format. A TikTok or Instagram ad prompt should include the offer, visual motion, and CTA.

```text
Create a vertical social ad for a sneaker spring drop. Show a white futuristic running shoe floating over liquid chrome with teal motion trails. Headline text: "SPRING DROP -20%". CTA text: "SHOP NOW". Energetic retail style, high contrast, readable text, 9:16.
```

```text
Create a YouTube thumbnail about AI image prompts. Split-screen layout, creator desk on the left, bold generated images on the right. Headline text: "PROMPTS THAT WORK". Add arrows and glow accents, but keep the design clean and readable. 16:9 thumbnail.
```

For social ads, ask for one main idea. Do not combine five products, four headlines, and three styles in one prompt. If you need variants, run several prompts with the same structure and change one variable at a time.

## Infographic And UI Mockup Prompts

Information design prompts need labels, order, and structure. Tell the model how many sections or cards you want.

```text
Create an editorial infographic titled "AI CITY 2030". Use an isometric smart city map with five labeled zones: "Solar Roofs", "Delivery Robots", "Autonomous Transit", "Water Sensors", "Energy Grid". Clean labels, arrows, dark background, cyan data lines, 16:9.
```

```text
Create a SaaS dashboard UI mockup for "StudioMetrics". Include a left sidebar, four metric cards, one line chart, one campaign table, and a top filter bar. Modern dark UI, emerald accent, readable labels, realistic spacing, 16:9.
```

These prompts are ideal for drafts and concept visuals. If you need a more detailed information design workflow, continue with the [GPT Image 2 infographic prompts guide](/blog/gpt-image-2-infographic-prompts).

## Prompt Checklist Before You Generate

Check these items before pressing generate:

- Is the exact text inside quotes?
- Is the channel or aspect ratio named?
- Is there one clear visual priority?
- Did you define what should not appear?
- Did you avoid asking for unrelated styles in one image?
- Is the prompt specific enough for a designer to execute?

GPT Image 2 can handle detailed instructions, but detail should reduce ambiguity. A long prompt full of loose adjectives is weaker than a compact prompt with subject, layout, text, and constraints.

## Final CTA

Use these GPT Image 2 prompts as templates, not fixed scripts. Replace the product, headline, format, and channel for your own workflow, then test variants in the [prompt library](/#prompts). For faster production, start with one asset type and build a small prompt system around it.
